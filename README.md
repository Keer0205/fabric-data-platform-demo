# Microsoft Fabric Data Platform Demo

End-to-end analytics demo built with **Microsoft Fabric** and **Power BI** to show how raw data can move through a modern reporting pipeline into a business-ready dashboard.

This project was created to demonstrate practical data platform skills across ingestion, transformation, modeling, and reporting in a simple portfolio format.

---

## Project Overview

This demo shows a typical analytics workflow using Microsoft Fabric:

- raw data is ingested into the platform
- data is transformed through a structured pipeline
- reporting-ready outputs are prepared
- a Power BI dashboard is used for business consumption

The goal is to present a clean example of how a modern data platform can support analytics and decision-making.

## Architecture / Flow

2. Data is processed and transformed using PySpark  
3. Refined data is prepared for reporting  
4. Power BI connects to the reporting-ready layer  
5. Dashboard is used for analysis and business insights  

---

## Why I Built This

I built this project to show an end-to-end analytics workflow using Microsoft Fabric and Power BI in a way that is practical, simple, and portfolio-friendly.

Many portfolio projects only show the final dashboard. I wanted this demo to reflect more of the actual platform thinking behind reporting, including data flow, transformation, and readiness for business use.
